PORTFOLIO PLAYER_01

Archivos principales:
- index.html: contenido y estructura de la página.
- style.css: colores, tipografías, distribución y adaptación a celulares.
- script.js: menú desplegable para pantallas pequeñas.
- assets/images/: carpeta reservada para las capturas de los tres juegos.

Para probarlo:
1. Extraé la carpeta completa.
2. Abrí index.html con Chrome, Firefox o Edge.
3. Para editar, abrí los archivos con Visual Studio Code u otro editor.

IMPORTANTE:
- Los tres espacios de imágenes son placeholders. Todavía no hace falta tener las capturas.
- La sección de contacto es un espacio reservado. No hay formulario falso ni envío de mensajes.
- Los enlaces "VER PROYECTO" son marcadores visuales por ahora. Cuando tengas enlaces reales de itch.io, GitHub u otra plataforma, reemplazalos.
- El nombre PLAYER_01 es provisorio y se puede personalizar.
- Las tipografías externas se cargan desde Google Fonts; si no hay conexión, se usarán fuentes alternativas.
