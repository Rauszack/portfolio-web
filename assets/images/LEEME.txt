IMÁGENES DEL PORTFOLIO

Cuando tengas las capturas de tus juegos, guardalas en esta carpeta con estos nombres:
- star-void.png
- profundidades.png
- godotventure.png

Por ahora, los espacios de las capturas son placeholders diseñados con CSS dentro de index.html.
Para colocar una imagen, reemplazá el bloque <div class="project-visual placeholder ..."> correspondiente por:

<div class="project-visual">
  <img src="assets/images/star-void.png" alt="Captura de Star/Void">
</div>

Cambiá el nombre del archivo y el texto alternativo para cada proyecto. Después agregá al final de style.css:

.project-visual img {
  width: 100%;
  height: 100%;
  min-height: 300px;
  object-fit: cover;
  display: block;
}

Recomendación: usar capturas horizontales, preferentemente 16:10 o 16:9.
